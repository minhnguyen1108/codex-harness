# Support
## Usage Questions
Use repository discussions or issues for usage questions when the topic is safe to discuss publicly.
## Bugs
Open an issue with the command run, expected result, actual result, operating system, and relevant file paths. Remove secrets and private logs before posting.
## Security
Use the private reporting guidance in [SECURITY.md](SECURITY.md) for security-sensitive behavior, suspected credential exposure, or exploit details.
## Expectations
This open source repository is maintained by the current maintainer as availability allows. There is no guaranteed response time.
