# Code of Conduct
## Expected Behavior
Be respectful, specific, and constructive. Focus criticism on code, docs, tests, and process.
## Unacceptable Behavior
Harassment, threats, discrimination, personal attacks, and deliberate disruption are not accepted.
## Enforcement
Report conduct concerns to `@minhnguyen1108` through the repository owner's preferred private GitHub contact path. The maintainer may remove content, close threads, or limit participation to protect the project.
